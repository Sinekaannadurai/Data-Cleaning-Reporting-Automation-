# Data Cleaning and Reporting Automation

This project automates the process of cleaning raw sales data and generating a professional report with visualizations using Python in Google Colab.

## 📌 Project Objective
To clean messy sales data, remove duplicates and missing values, and generate a final report with charts automatically.

## 🛠 Tools & Technologies Used
- **Language**: Python
- **Libraries**: Pandas, Matplotlib, OpenPyXL
- **Platform**: Google Colab
- **Output Formats**: Excel (.xlsx), PNG Chart

## 📂 Files Included
1. `Raw_Sales_Data.xlsx` - Original dataset with sample sales records
2. `Data_Cleaning_Reporting.ipynb` - Jupyter Notebook with complete automation code
3. `Cleaned_Report_2026-08-20.xlsx` - Cleaned and processed data with new columns
4. `Sales_Report_Chart.png` - Bar chart showing Total Sales by Region

## ⚡ Key Features
- Data cleaning: Handle missing values and duplicates
- Feature engineering: Added `Total_Sales` column
- Automated Excel report generation
- Data visualization: Sales by Region chart
- 100% reproducible in Google Colab

## 🚀 How to Run
1. Open `Data_Cleaning_Reporting.ipynb` in Google Colab
2. Upload `Raw_Sales_Data.xlsx`
3. Run all cells
4. Download the cleaned report and chart

## 📊 Sample Output
Cleaned data + Visualization chart generated automatically
